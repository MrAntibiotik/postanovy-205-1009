# Постанови КМУ № 205 і № 1009 — навчальний інструмент

Відкрити: https://mrantibiotik.github.io/postanovy-205-1009/

Один файл `index.html` без збірки й залежностей. GitHub Pages: гілка `main`, папка `/ (root)`.

Матеріал навчальний, не є офіційним тлумаченням. Перед використанням у робочих документах звіряти з чинною редакцією на https://zakon.rada.gov.ua.

## Android-застосунок

Завантажити APK: https://github.com/MrAntibiotik/postanovy-205-1009/releases/latest/download/postanovy-205-1009.apk

APK збирається автоматично (GitHub Actions, `.github/workflows/android.yml`) після кожної зміни `index.html` або папки `android/`. Застосунок показує той самий `index.html` усередині WebView і працює без інтернету; прогрес зберігається окремо від браузера.
